# Todo App

A simple Todo app built mainly to explore a preferred backend architecture in Python.

The project focuses on:

- A 4-layer architecture with dependency inversion.
- Keeping clear boundaries between modules, particularly `User` and `Todo`.
- Using clients to communicate between modules without coupling them directly.
- Applying dependency injection and separation of concerns in a small, practical project.

## Features

- User signup
- User login
- Check user information
- Create todos
- Get todos
- Update todos
- Delete todos

The goal is less about building a feature-rich Todo app and more about experimenting with how to structure a modular Python backend that can remain maintainable as it grows.
